# 炎上・トラブルのリスクチェック

技術ブログの炎上は、悪意よりも「言い方」と「うっかり」で起きることが多い。
次の項目を**すべて**確認する。

## 1. 機密情報・個人情報の露出（最重要）
コードブロック、スクリーンショットの説明文、ログの貼り付けも含めて確認する。

- [ ] Databricks のワークスペース URL（`https://adb-xxxx.azuredatabricks.net`、`https://dbc-xxxx.cloud.databricks.com` など）
- [ ] ワークスペース ID、組織 ID、クラスター ID、ジョブ ID、ウェアハウス ID
- [ ] アクセストークン（`dapi...`）、シークレット、接続文字列、クラウドのアカウント ID、ARN、サブスクリプション ID
- [ ] S3 / ADLS / GCS のバケット名・パスから会社名やプロジェクト名が分かるもの
- [ ] カタログ名・スキーマ名・テーブル名・カラム名から、勤務先や顧客の業務内容が推測できるもの
- [ ] 実データ（氏名、メール、住所、健康データ、金額など）。サンプルデータは架空のものに置き換えるよう提案する
- [ ] 社名・顧客名・同僚の名前、社内でしか知られていない情報（未公開の製品、組織体制、障害情報）
- [ ] 勤務先の就業規則や情報発信ポリシーに触れそうな内容（業務で得た知見をそのまま書いていないか）

見つけたら 🔴 とし、`<your-workspace>`、`main.sample_schema.orders` のようなプレースホルダーへの置き換えを提案する。

## 2. 断定・誇張
- [ ] 「〇〇は使えない」「〇〇一択」「〇〇はオワコン」「〇〇しないのは時代遅れ」
- [ ] 「必ず」「絶対に」「誰でも」「最強」「完全に理解した」（ネタとして明らかな場合は除く）
- [ ] 1回の検証結果を一般化している（「Photon は 3 倍速い」→ 条件次第）

**言い換え例**
| 元の表現 | 修正案 |
|---|---|
| 〇〇は使い物にならない | 今回のユースケース（〜〜）では、〇〇は合いませんでした |
| △△一択です | 私の環境では △△ がいちばん扱いやすかったです |
| Photon で 3 倍速くなります | 私の検証（DBR 15.4 LTS, i3.xlarge × 2, 約 1 億行）では、処理時間が約 1/3 になりました |

## 3. 他者・他社・他製品への批判
- [ ] 競合製品（Snowflake, BigQuery, Fabric など）を根拠なく下げていないか。比較するなら条件と出典を書く
- [ ] 他の人の記事や OSS、公式ドキュメントを揶揄していないか（「公式ドキュメントが不親切すぎる」→「公式ドキュメントだけでは〜が分からず、〜で確認しました」）
- [ ] 前職・現職・顧客・チームメンバーへの不満と読める記述
- [ ] 「〜も知らない人が多い」「初心者はよく〜」のような、読者を見下す書き方

## 4. 根拠・出典・鮮度
- [ ] 料金・性能・制限値（クォータ、上限）を書くとき、出典 URL と確認日があるか
- [ ] プレビュー機能 / ベータ機能を GA のように書いていないか
- [ ] Databricks Runtime（DBR）のバージョン、クラウド（AWS / Azure / GCP）、Unity Catalog 有無などの前提が書いてあるか。冒頭に「検証環境」をまとめることを提案する
- [ ] 他人のコード・図・文章を引用するとき、出典とライセンスを明記しているか（引用の範囲を超える転載がないか）

## 5. センシティブな話題・不適切語
- [ ] 性別・年齢・国籍・障害などに触れる表現、不要な比喩（「〇〇でも分かる」の〇〇に属性を入れるなど）
- [ ] 政治・宗教・事件事故を例え話に使っていないか
- [ ] 「マスター/スレーブ」など、置き換えが進んでいる用語（→ プライマリ/レプリカ、allowlist/denylist など）。製品の正式名称として残っている場合は除く

## 6. セキュリティ上まずい手順の紹介
- [ ] トークンをノートブックに直書きする例 → Databricks Secrets（`dbutils.secrets.get`）を使う例に直す
- [ ] 権限を `ALL PRIVILEGES` や管理者権限で雑に付与する手順を、注意書きなしで紹介していないか
- [ ] 「とりあえず動いた」設定（パブリックアクセス許可、SSL 検証無効化など）を推奨手順のように書いていないか。書くなら `:::message alert` で注意を添える
